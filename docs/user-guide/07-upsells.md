# 7. Upsells

An upsell rule suggests a second service to a customer after they request a first one, for example offering a flu shot to someone requesting a consultation.

## Creating a rule

1. Go to Upsell Rules and click New Rule.
2. Choose the trigger service and the suggested service.
3. Set how often it fires: every Nth customer requesting the trigger service, or a percentage of them.
4. Optionally limit it by customer age, visit type, active dates, active hours, and a cooldown period so the same customer isn't asked too often. Age and visit type only appear if your organization collects date of birth.
5. Set a daily or hourly conversion limit if needed.
6. Write the prompt shown to the customer: a title, description, and accept button text.
7. Turn on A/B testing to try more than one version of the prompt. The best-performing version is shown 90% of the time, the rest for testing.
8. Save.

## Where customers see it

The upsell prompt appears right after a matching walk-in or kiosk request, once the customer has their own queue number. The customer can accept it immediately, book it for later, or decline. Accepting or booking gives them a second queue number for the suggested service.

## Managing rules

- **Reorder** rules to control which one applies first when more than one could match.
- **Activate or deactivate** a rule without deleting it.
- View each rule's stats: how often it was accepted, booked later, or declined, over today, this week, this month, or all time.
- **Delete** a rule you no longer need.
- **Age and visit type targeting** need date of birth collection turned on (Settings, under Organization details). Turn it off and these fields disappear from the rule until you turn it back on. Existing values are kept, not deleted.

## Plan limits

The Starter plan allows 1 upsell rule. The Business plan has no limit.
