# 5. Managing the Queue

## The queue screen

The Queue page shows three lists: waiting, in progress, and completed today, plus stats for total requests and (if enabled) average wait time. Filter by service using the service checkboxes at the top.

## Adding a walk-in

1. Go to Queue and click Add Walk-in.
2. Choose the service.
3. Enter the customer's name and any required details.
4. Submit. The customer gets a queue number.

If the customer qualifies for an upsell, you'll see the upsell screen next, before the queue number is assigned to the suggested service. See Upsells.

## Calling and updating customers

- **Call next** moves the next waiting customer into progress.
- Change a customer's status directly: mark in progress, completed, or cancelled, or send them back to waiting.
- Restore the most recently cancelled customer to waiting from the queue toolbar.
- Revert a completed or cancelled request individually from its row if you made a mistake.

## Wait timer

If the waiting time feature is on, average wait time appears on the queue screen and the waiting display. Reset the timer from the queue page to start a new averaging window, for example at the start of a new day.

## Waiting display

The waiting display is a full-screen view for a TV in your waiting area, showing who's waiting and who's currently being served.

1. Open the Waiting Display page while signed in as staff.
2. The browser remembers this device for 30 days, so you don't need to sign in again each time.

Anyone using that device can reach the waiting display without logging in again during those 30 days, so only use it on a device you control.
